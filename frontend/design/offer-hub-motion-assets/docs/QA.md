# 动效交付校验

- 6 组角色动作，每组 8 帧；有 5–7 个不同画面，部分姿态回用以闭合循环。已经逐帧查看手部、道具与表情变化。
- 动态 WebP、CSS 序列图、静态封面、SVG 与预览所需原素材均完成解码检查，网页图片共 66 份，单张最大 148,464 字节。
- 6 张生成原稿与 48 张逐帧 PNG 完成解码检查；透明角色保留 alpha。
- 动态 WebP 检查 8 帧页数、实际逐帧延时、总时长与循环次数。挥手与庆祝播放一次，其余默认循环。
- 预览在桌面 1440×1080、移动 390×844 下分别检查亮暗主题，无页面横向溢出、页面脚本异常或已加载破图。
- 浏览器实际检查：CSS 帧位置推进、一次性动作结束、离屏停止、系统 reduced-motion，以及手动关闭时伪元素动画停止。
- React 18 组件实际运行检查：逐字显示、运行中调速不回退、显示全文、完成回调只触发一次、动作重播、disabled 静态降级、系统减少动效、受控收藏状态、进度边界限制。
- TSX 与类型化资源索引通过 TypeScript 严格检查。
- 最终 ZIP 执行 CRC 完整性检查；`SHA256SUMS.txt` 提供各文件校验值。

本包不含完整业务后端或实时口型／Live2D。业务流程、网络延迟及最终站点 LCP／CLS 需在集成后测量；动效播放结束不代表接口保存成功。
