# 页面适用规则

| 页面 | 亮色桌面 | 暗色桌面 | 移动端 | 限制 |
| --- | --- | --- | --- | --- |
| 首页 | hero_cover；独立 HTML 搜索与标题 | hero_cover_dark | 优先纯底搜索卡；需要角色时改用墨樱小头像 | 主视觉一位角色；艺术区域不超过视口约 20% |
| 题库页 | 编辑式 Bento；无题库时 empty_bookmarks | 同一透明小图配暗底 | 单列信息卡；小图 120–160px | 有内容时不在题库卡塞入角色 |
| 题目列表 | 高密度列表；搜索无结果时 empty_search | 同一透明图 | 筛选优先；空状态图不遮挡筛选 | 不用角色或装饰压缩首屏题数 |
| 题目详情／阅读 | 纯文档模式 | 纯文档模式 | 纯文档模式 | 代码与表格保持真实 DOM |
| 题目详情／模拟面试 | scene_interview_day + 一位立绘 | scene_interview_night + 一位立绘 | 对应表情图集中的头像 + 底部选项抽屉 | 对话框不超过 35dvh；长代码切到全宽面板 |
| 登录 | scene_login + 墨樱或一位面试官 | scene_interview_night + 同一角色 | 低对比背景、姓名牌头像与独立表单 | 同屏最多一位角色；表单文字放在独立实色底 |
| 404 / 错误 | scene_error + lost Q 版 | scene_error 加暗色遮罩 + lost Q 版 | lost Q 版 144px；背景可省略 | 404 / 返回按钮用 HTML |
| 网络异常 | state_network_error | 同一透明图 | 120–160px | 天青仅提示；重试为墨色按钮 |
| 新手引导 | state_onboarding 或 welcome Q 版 | 同一透明图 | 紧凑插画 + 44px 触控目标 | 二者择一，不同时堆叠 |
| 掌握里程碑 | state_mastery 或 celebrating Q 版 | 同一透明图 | 120–160px | 樱红用于进度与奖励 |

## 两种风格的边界

Light Novel Bento 用在首页及概览区：12 栏、160px 单位高度、1px 墨线、0 圆角、0 阴影。插画只出现在规范允许的主视觉、空状态、加载、错误、引导与里程碑中。

Visual Novel 用在模拟面试、登录、错误舞台：背景、一个角色、姓名牌、对话框和真实操作选项分层渲染。字体和选项不包含在背景图片内；场景可按需施加 1–2px 轻微模糊，对话框独立用 88% 墨色与 12px backdrop blur。

## 组件对应

| 组件 | 素材来源 | 实现要点 |
| --- | --- | --- |
| BentoGrid | 无位图 | 布局与墨线用 CSS |
| BentoCard | heroes 或许可场合的 states | 主视觉仅一位角色；可读文字为独立 DOM |
| VNStage | scenes + characters | 分层；只加载当前角色和当前场景 |
| DialogueBox | 无位图 | 墨色透明底、宋体台词、可访问的推进按钮 |
| NameTag | 图集头像可选 | 樱红姓名牌；名字为文字 |
| ChoiceList | 无位图 | 天青只用于选项高亮；真实按钮 |
| Backlog | 无位图 | 显示完整解析；支持滚动和 Esc 返回 |

## 图集使用

原始图集 1536 × 1024，共 3 × 2 格，每格 512 × 512。CSS background-size: 300% 200%，横向位置依次 0%、50%、100%，纵向为 0%、100%。以 manifest.json 的最终尺寸为准。不要把整张六格图直接作为移动端头像。半身图下缘是平切的设计裁切，不适合充当全身透明立绘。

## 安全区与性能

首页封面实际内容比提示词预期更靠左，保守文案安全区为左侧 0–40%，需要更宽搜索框时将图片放在单独的右侧容器，而非把文字直接压在图上。暗色封面单独提供，勿使用 CSS invert 处理人物。

PNG 为设计母图，不受 150KB 网页加载限制；生产使用 web/。首屏只预载一张实际需要的图，其他图 loading=lazy。图片设置 width/height 或稳定 aspect-ratio，减少位移。完整图集可在头像需要时单次下载并复用。prefers-reduced-motion 开启时，关闭逐字与转场，不把静态 Q 版切换伪装成流畅动画。

字体、WebP 导出和布局预算不能代替实际 LCP/CLS 测试。题目正文至少 15px，辅助文字至少 13px；所有关键文案都在可验证的实色底上，避免直接覆在复杂插画上。
